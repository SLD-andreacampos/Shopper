Preguntas frecuentes

Respuestas breves basadas en los procedimientos del manual. Cada respuesta enlaza al apartado completo.

Promotor y app

¿Por qué no aparece Jornada / Fichaje?

El administrador debe comprobar que el cargo tenga habilitado Panel de Control › Gestión de roles › App › Aplicación móvil - Jornada / Fichaje.

Abrir el procedimiento completo →
¿Cómo sé si mi jornada ha comenzado correctamente?

La pantalla debe mostrar el estado En curso y la hora de Entrada registrada.

Abrir el procedimiento completo →
¿Cómo termino un descanso?

Abre Jornada / Fichaje y pulsa Fin de descanso. La actividad mostrará el intervalo completo del descanso.

Abrir el procedimiento completo →
¿Cómo sé si la jornada ha finalizado?

Debe aparecer Jornada completada, el estado Completada y las horas de entrada, descanso y salida.

Abrir el procedimiento completo →
¿Registro de trayectos es lo mismo que Rutas?

No. Rutas muestra la planificación de visitas. Registro de trayectos guarda desplazamientos realizados y aparece como módulo independiente.

Abrir el procedimiento completo →
¿Por qué no aparece Registro de trayectos?

El administrador debe comprobar el permiso Panel de Control › Gestión de roles › App › Aplicación móvil - Registro Trayectos.

Abrir el procedimiento completo →
¿Qué hago si una dirección no aparece al registrar un trayecto?

Comprueba la conexión y escribe una dirección más completa. Antes de guardar, revisa en el mapa el orden de las paradas y el destino.

Abrir el procedimiento completo →
¿Por qué no puedo finalizar una visita?

Revisa que las tareas requeridas y sus campos obligatorios estén completados antes de abrir Check-out.

Abrir el procedimiento completo →

Altas y gestión

¿Dónde se da de alta un Punto de Venta?

Abre Gestión › Gestión Puntos de Venta y utiliza Nuevo punto de venta para el alta unitaria.

Abrir el procedimiento completo →
¿Cómo asigno establecimientos a un empleado?

Abre Asignación PDV–usuarios y utiliza Crear para una asignación individual o Alta masiva para trabajar con la plantilla.

Abrir el procedimiento completo →
¿Dónde se crea un empleado?

Abre Gestión › Gestión Empleados y utiliza Nuevo empleado. El procedimiento separa los datos del empleado, usuario y gestión de cuentas.

Abrir el procedimiento completo →
¿Eliminar un elemento del catálogo lo borra definitivamente?

En el catálogo, la acción Eliminar desactiva los registros seleccionados.

Abrir el procedimiento completo →

Cargas y plantillas

¿Debo utilizar una plantilla diferente para cada carga masiva?

Sí. Descarga la plantilla del módulo correspondiente: cada proceso utiliza sus propias columnas y validaciones.

Abrir el procedimiento completo →
¿Dónde consulto los errores de una carga masiva?

Abre Ver Hco. Cargas y entra en el detalle de la carga con errores. Corrige el archivo antes de repetir la carga.

Abrir el procedimiento completo →
¿En qué formato preparo una carga masiva?

Cuando el procedimiento lo indique, guarda la plantilla como CSV delimitado por comas, sin líneas vacías finales y respetando el límite de 4 MB.

Abrir el procedimiento completo →
¿Dónde están las plantillas oficiales?

Cada procedimiento enlaza su plantilla correspondiente. La página Primeros pasos reúne accesos directos a las cargas principales.

Abrir el procedimiento completo →

Formularios Avanzados

¿Dónde añado secciones, campos y dependencias?

En Formularios Avanzados, completa Configuración y Estructura y control; después abre Diseño y utiliza Añadir.

Abrir el procedimiento completo →
¿Qué tipos de campo puedo utilizar?

El selector incluye Archivo, Buscador, Calificación, Check, Email, Escala lineal, Fecha, Firma, Imagen, Numérico, Selectores, Texto libre, Título, Ubicación y Vídeo.

Abrir el procedimiento completo →
¿Qué ocurre al eliminar un Formulario Avanzado?

Si no tiene reportes asociados se elimina; cuando existen reportes asociados, se desactiva.

Abrir el procedimiento completo →
¿Cómo compruebo un formulario desde la app?

Durante una visita, abre Tareas, completa los campos obligatorios, pulsa Guardar y comprueba que el formulario figure como completado.

Abrir el procedimiento completo →

Informes

¿Qué hago si un informe no devuelve resultados?

Revisa el tipo de informe, el intervalo de fechas y los filtros aplicados. Un resultado vacío puede deberse al periodo o a la selección.

Abrir el procedimiento completo →
¿Dónde consulto fotografías de Formularios Avanzados?

Abre Informes › Fotos Formularios Avanzados y selecciona el formulario, el usuario y los filtros disponibles.

Abrir el procedimiento completo →
¿Dónde consulto el recorrido de un usuario?

Abre Informes › Tracking, indica las fechas y selecciona el usuario antes de buscar.

Abrir el procedimiento completo →

Administración

¿Cómo habilito una función para un cargo?

Abre Panel de Control › Gestión de roles, localiza el cargo, pulsa el engranaje y revisa los módulos Web o App.

Abrir el procedimiento completo →
¿Dónde se configura la disponibilidad de valores maestros?

En Panel de Control › Componentes maestros, selecciona la tabla y utiliza Activar o Desactivar sobre el valor correspondiente.

Abrir el procedimiento completo →
¿Por qué un usuario no ve una función de la app?

Comprueba el cargo del usuario y los permisos de la pestaña App dentro de Gestión de roles.

Abrir el procedimiento completo →
